# Catálogo de efeitos — API em português

Use os nomes em português abaixo. Os nomes antigos em inglês continuam funcionando para não quebrar projetos existentes.

| Nome intuitivo | Classe recomendada | Origem |
|---|---|---|
| Painel de vidro | `bfx-painel-vidro` | Base da biblioteca |
| Elevação ao passar o mouse | `bfx-elevar-hover` | Matrix |
| Borda brilhante | `bfx-borda-brilhante` | Matrix |
| Entrada suave | `bfx-entrada-suave` | Base |
| Textura granulada | `bfx-textura-granulada` | Matrix |
| Sublinhado animado | `bfx-link-sublinhado` | Matrix |
| Botão com preenchimento | `bfx-botao-preenchimento` | Base |
| Botão contorno com brilho | `bfx-botao-contorno-brilho` | Matrix |
| Link com seta móvel | `bfx-link-seta` | Base |
| Card com zoom de imagem | `bfx-card-zoom-imagem` | Base |
| Sobreposição no card | `bfx-card-sobreposicao` | Base |
| Card flutuante | `bfx-card-flutuante` | Base |
| Faixa infinita | `bfx-faixa-infinita` + `bfx-faixa-infinita-trilho` | Base |
| Botão cibernético | `bfx-botao-cibernetico` | Matrix |
| Cubo giratório 3D | `bfx-cubo-giratorio` | Matrix |
| Chuva Matrix | `bfx-chuva-matrix` | Matrix |
| Busca cápsula | `bfx-busca-capsula` | Nike |
| Botão de ícone | `bfx-botao-icone` | Nike |
| Palco de produto | `bfx-palco-produto` | Nike |
| Fundo holofote | `bfx-fundo-holofote` | Nike |
| Sobretítulo com linha | `bfx-sobretitulo` | Matrix |
| Card de revelação | `bfx-card-revelacao` e subpartes | Matrix |
| Alternador de tema | `bfx-alternador-tema` e `bfx-escopo-tema` | Matrix |
| Conteúdo exclusivo por tema | `bfx-apenas-tema-a` / `bfx-apenas-tema-b` | Matrix |
| Texto pulsante | `bfx-texto-pulsante` | Matrix |
| Foco visível | `bfx-foco-visivel` | Nike / acessibilidade |
